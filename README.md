# cplus-bench

Public, reproducible cases where an AI agent proposes a C/C++ patch and cplus checks it. This repository contains case metadata, unchanged agent patches, and generated verification summaries. The cplus verifier is maintained separately.

## Reading a case

`cases/<id>/case.yaml` identifies the upstream repository, broken base commit, upstream fix, bug test, issue, license, and exact agent identity. `agent-fix.patch` is the agent's original output; an empty file means no agent has run. `results/<id>.md` is generated from verifier output. A missing or pending result is not a verdict.

## Method

Cases are selected from real upstream fixes. Before inclusion, the fixed test is run against the broken base with `cplus bug --from-fix` and must reproduce. The agent is then shown only a source tree at the broken base and the issue text. Its first patch is preserved byte for byte. cplus independently checks the patch against a BugSpec bound to that base and reports a verdict and eight checks. Infrastructure failures are reported as such, never as a passing result. See [protocol](docs/protocol.md).

The upstream fix and case metadata are public for audit, but are excluded from the agent's isolated workspace. Verification summaries are generated by the workflow after the owner completes [setup](docs/owner-setup.md). No benchmark outcome is claimed in this README.
