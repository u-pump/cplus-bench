# Agent and verifier protocol

1. The curator selects an upstream C/C++ CMake/CTest bug with a precise broken commit, a later fix, and a test added or strengthened by that fix. The curator runs `cplus bug --from-fix` on the broken commit. A case is eligible only when the bug is reproduced. Record the elapsed time separately from any agent run.
2. Freeze the public issue body or a dated issue excerpt, the broken commit, and a hash of the agent input. The agent receives a clean source snapshot at the broken commit and that issue text only. Do not mount this benchmark repository, upstream fix commits, fix-only tests, cplus binaries/source, previous results, or the curator's git credentials into the agent workspace. A normal clone with future git history is not an acceptable agent input.
3. Record the agent product, exact model/version, invocation, start time, input hash, and patch hash in `case.yaml` before judging. Save the first emitted unified diff unchanged as `agent-fix.patch`; no human edits or retries within the same attempt. An empty patch means the agent has not run.
4. On the verifier side, reconstruct the upstream base and the upstream fix test, create a BugSpec using `cplus bug --from-fix`, then run `cplus verify --project <base> --patch agent-fix.patch --bug-spec <spec> --json`. The verifier keeps its private logs and source. The public report contains only verdict, the eight check names/statuses, and elapsed time. Failures to clone, build, reproduce, or verify are infrastructure errors, not code verdicts.
5. The owner reviews case provenance and generated results before publishing any aggregate results in README.

## Local isolation on Windows

Use a dedicated Linux VM, rather than an ordinary Windows process. Put the VM disk and exported broken-base snapshot under `D:\c-plus-data\bench\agent\`. Give the VM only that snapshot and the frozen issue text, through an input-only share or copied archive. Do not share `D:\c-plus-codex`, `D:\c-plus`, or any other `D:\c-plus*` path; exclude Windows host drives, Docker Desktop integration, SSH agent, host credentials, and the host network. Export only a unified diff to `D:\c-plus-data\bench\agent-output\` after the run. The verifier runs outside the VM. Check C: has at least 3 GB free before preparing the snapshot or VM disk. This describes a future agent run; none is part of the case-selection step.
