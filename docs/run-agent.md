# Запуск агента владельцем

Для каждого кейса используйте только его приватный `u-pump/bench-in-<id>`. Из корня `cplus-bench` запустите один раз:

```powershell
pwsh -File scripts/run-agent-local.ps1 -Agent claude-code <id>
```

Для Codex CLI используйте `-Agent codex-cli`. Скрипт клонирует один коммит во временный каталог `D:\c-plus-codex\.tmp\bench-agent`, передаёт неизменённый `TASK.md`, сохраняет первый diff в `cases/<id>/agents/<agent-id>/agent-fix.patch` без каталогов `build*/`, записывает `agent.yaml` с моделью, версией и SHA-256 и удаляет клон. Журнал остаётся в `cplus-bench/.tmp/agent-runs/logs/`. При сбое связи или отсутствии выполненных действий файлы попытки не меняются.

Claude Code CLI должен быть установлен и авторизован. При отсутствии CLI скрипт даст ссылку на установку и инструкцию входа. При API-ключе скрипт включает `--bare`, чтобы исключить пользовательские настройки, память и `CLAUDE.md`. В остальных режимах входа используется `--restricted`; возможная загрузка `CLAUDE.md`, а также отсутствие изоляции сети, файлов хоста и сохранённых учётных данных у Bash/PowerShell фиксируются в `agent.yaml`. Для строгой изоляции запускайте скрипт на отдельной машине без доступа к репозиторию benchmark и секретам куратора. После запуска отправьте отдельный PR с патчем. Не редактируйте патч и не повторяйте попытку в том же кейсе.
