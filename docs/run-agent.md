# Запуск агента владельцем

Агент ещё не запускался. Для каждого кейса используйте только его приватный `u-pump/bench-in-<id>`.

1. Откройте [chatgpt.com/codex](https://chatgpt.com/codex) → **Environments** → **Create Environment**. Если GitHub не подключён, нажмите **Connect to GitHub** и разрешите доступ только к нужному `bench-in-<id>`. Выберите этот репозиторий и создайте окружение. Не подключайте `cplus-bench` или `c-plus`; выключите доступ агента в интернет, не добавляйте секреты и setup-скрипты.
2. В новом окружении начните задачу в режиме **Code**. Вставьте текст `TASK.md` дословно. Выберите модель и сохраните её точное название. Не добавляйте другие инструкции или файлы.
3. После **первого** завершённого ответа откройте **Changes**, сохраните ссылку на задачу и не просите доработок. Создайте PR в этом приватном входном репозитории из первого результата. Для получения patch-файла из PR выполните `gh pr diff <номер> -R u-pump/bench-in-<id> --patch --color never --allow-escape-sequences > cases/<id>/agent-fix.patch` из корня `cplus-bench` с учётной записью, имеющей доступ к приватному репозиторию. Сохраните файл без правок.
4. В `cases/<id>/case.yaml` замените `agent: null` на объект с `name`, `model`, `version`, `date_utc`, `task_url`, `patch_sha256`; `version` — точное название модели, которое попадёт в публичный отчёт. Убедитесь, что `input_sha256` не менялся. Коммитьте только `agent-fix.patch` и `case.yaml` в отдельную ветку `cplus-bench`, затем откройте PR. Проверку запустит владелец после просмотра первого diff.

Если интерфейс отличается или PR не содержит ровно первый diff, остановитесь и сохраните исходный diff из задачи без ручной правки. [Справка Codex Cloud](https://help.openai.com/en/articles/20001545-using-codex-cloud).
