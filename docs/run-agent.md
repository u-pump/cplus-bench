# Запуск агента владельцем

Для каждого кейса используйте только его приватный `u-pump/bench-in-<id>`. Все ваши действия — в браузере.

1. Откройте [chatgpt.com/codex](https://chatgpt.com/codex) → **Environments** → **Create Environment**. Если GitHub не подключён, нажмите **Connect to GitHub**. Выберите только `u-pump/bench-in-<id>`, выключите интернет для окружения, не добавляйте другие репозитории, секреты или setup-скрипты.
2. Создайте задачу в режиме **Code**. Вставьте текст `TASK.md` дословно и запишите точное название выбранной модели.
3. После первого ответа откройте **Changes** и создайте PR в том же приватном `bench-in-<id>`. Не редактируйте diff и не просите агента о второй попытке.
4. Пришлите Codex ссылку на этот PR и название модели.

Codex сам скачает первый diff, сохранит `agent-fix.patch` без правок, рассчитает `patch_sha256`, заполнит `case.yaml` и откроет отдельный PR в `cplus-bench`. [Справка Codex Cloud](https://help.openai.com/en/articles/20001545-using-codex-cloud).
